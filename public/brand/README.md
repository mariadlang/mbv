# Assets públicos de marca

Este directorio documenta el futuro paquete de marca; P1 no añade ni sustituye imágenes aquí. Los assets vigentes continúan en la raíz de `public/` para preservar sus URLs.

- `/brand-icon.svg` es la fuente temporal activa del símbolo.
- `brand-icon.png`, `favicon.png`, `og.png` y `og-v2.jpg` se conservan aunque algunos no tengan referencias internas activas.
- `app/opengraph-image.tsx` genera la pieza social vigente.

No redibujar el símbolo, generar variantes, mover archivos ni retirar duplicados hasta contar con el vector maestro aprobado y un inventario de usos externos. Consultar `docs/brand/assets-manifest.md` y `docs/brand/logo-assets-status.md`.
