# Jerarquía de mensajes de My Best Version

## Fuente de verdad

Las constantes implementadas en `src/lib/brand.ts` son la fuente reutilizable para superficies de producto y adquisición. Esta jerarquía separa la promesa, la firma emocional y la explicación de funcionamiento.

| Nivel | Mensaje aprobado | Función |
| --- | --- | --- |
| Nombre | **My Best Version** | Identificación oficial del producto |
| Promesa principal | **Tu vida completa, organizada con claridad y sin culpa.** | Beneficio principal y encabezado de adquisición |
| Idea rectora | **Progreso amable.** | Criterio de producto y de experiencia |
| Posicionamiento | **Productividad consciente para una vida multidimensional.** | Categoría y territorio competitivo |
| Mensaje estratégico | **De la visión a la acción, con tu tiempo, tus hábitos y tu dinero conectados.** | Explicación estratégica del sistema |
| Slogan emocional | **Una vida más tuya.** | Firma breve de marca |
| Explicación operativa | **Convierte la vida que quieres construir en decisiones que caben en hoy.** | Explica cómo se materializa la promesa |

## Uso por superficie

| Superficie | Mensaje principal | Mensaje de apoyo |
| --- | --- | --- |
| Landing | Promesa principal | Posicionamiento como eyebrow y explicación operativa como cuerpo |
| Metadata | `My Best Version · Una vida más tuya.` | Promesa principal como descripción |
| Open Graph | Nombre y promesa principal | Slogan como firma; dominio como dato secundario |
| Signup | Acción de crear una cuenta | El slogan puede aparecer como narrativa, no como CTA |
| Login | Continuidad del espacio existente | Copy funcional de acceso |
| Onboarding | Slogan como bienvenida | Promesa como apoyo y CTA “Crear mi primera acción” |
| Producto autenticado | Nombre y navegación | Copy contextual de cada tarea; no repetir la plataforma completa |
| Paywall | Capacidad concreta bloqueada | Explicación transparente del acceso y conservación local |

## Reglas de uso

1. No presentar promesa, slogan y explicación operativa como equivalentes.
2. No apilar todos los mensajes estratégicos en una misma pantalla.
3. La promesa puede ser el H1 principal; el slogan funciona como firma, no como descripción funcional.
4. Los CTA deben nombrar la acción real y no reutilizar frases emocionales.
5. El posicionamiento es un descriptor de categoría, no una promesa comercial adicional.
6. El mensaje estratégico se reserva para contextos que explican el sistema completo.
7. La idea rectora guía decisiones internas y puede aparecer de forma contenida en producto; no debe convertirse en una etiqueta repetitiva.
8. Mantener “My Best Version” sin abreviaturas visibles como marca principal.
9. No introducir nuevos monogramas, slogans o promesas sin aprobación explícita.
10. En una pieza pequeña, priorizar nombre + promesa o nombre + slogan; no los siete niveles.

## Mensajes retirados

- `Planea · Acciona · Logra.`
- `Planea · Haz · Vive · Avanza.`

Estos mensajes no deben reaparecer en landing, navegación, metadata, Open Graph, onboarding ni paywalls.
