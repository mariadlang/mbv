# Fuentes de producto y marca

Los documentos funcionales, prompts, mockups y brand kits suministrados son **fuentes históricas de contexto**, no autoridad automática sobre el producto vigente. Los originales permanecen fuera del repositorio para no duplicar archivos personales ni tratar material no versionado como evidencia aprobada.

El orden actual de autoridad es:

1. código implementado y verificable;
2. documentación P0/P1 vigente;
3. decisiones de marca expresamente aprobadas;
4. ADR vigentes;
5. documentos históricos, sólo como referencia.

Las decisiones actualmente verificables incluyen planificación conectada con metas, constancia calculada sólo sobre días programados, progreso por hitos o tareas, diario y bienestar, privacidad local-first, Nunito Sans y la paleta documentada. Si una fuente externa contradice el código o los documentos vigentes, se clasifica como reemplazada, histórica o pendiente de decisión antes de aplicarla.
