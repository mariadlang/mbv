# Fuentes de producto y marca

La implementación toma como autoridad el documento funcional v1.1 y el brand kit suministrados. Sus decisiones principales quedan reflejadas en el código: planificación semanal conectada con metas, constancia calculada sólo sobre días programados, progreso por hitos/tareas, mood y journal, privacidad local-first, y un lenguaje visual editorial en marfil, carbón, rosa evolución, taupe, salvia y blush.

El prompt de proyecto se usó como contrato de alcance técnico y de calidad. Los PDF originales permanecen fuera del repositorio para no duplicar documentos de trabajo personales.
