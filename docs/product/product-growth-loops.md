# Loops de producto y crecimiento

**Principio:** valor personal primero. Cada loop debe seguir siendo útil aunque la usuaria ignore Premium, sharing o referral.

| Loop | Secuencia real | Momento de valor | CTA permitido | Métrica | Guardrail |
| --- | --- | --- | --- | --- | --- |
| Activación | Resultado → primera acción conectada → Mi día → acción realizada o reprogramada conscientemente → segunda sesión | La primera evidencia de avance | `Continuar en Mi día` | activación v2 en 7 días | No contar sólo crear cuenta o abrir la app |
| Planificación | Visión/meta → mes → semana → día → revisión → nueva decisión | Una semana preparada y revisada | `Preparar mi semana` | semanas planificadas y revisiones | No castigar acciones abiertas |
| Hábitos | Hábito elegido → registro en día programado → patrón visible → ajuste → continuidad | Consistencia sobre días elegidos | `Ver mi ritmo` | registros / días programados | Sin rachas punitivas ni comparar usuarias |
| Reflexión | Experiencia → nota privada → revisión → insight propio → decisión | La usuaria encuentra un aprendizaje | `Guardar mi revisión` | revisión creada | El texto nunca sale a analytics ni sharing |
| Premium | Valor actual → límite real → beneficio específico → elección | La usuaria entiende qué desbloquea | `Ver Premium` | gate → checkout → pago | Sin interrupciones repetidas ni claims emocionales |
| Sharing | Avance → selección → preview → acción explícita → export/share | Reconocimiento personal | `Crear una tarjeta` | opened → created → shared | Nada sensible ni publicación automática |
| Referral | Valor recibido → recomendación opcional → visita → registro → activación | La usuaria decide recomendar | `Compartir My Best Version` | visit → signup → activation | Código opaco; no revelar quién invitó |
| Retorno | Varios días fuera → bienvenida neutral → revisar/mover/soltar/elegir mínimo | Recuperar control sin culpa | `Retomar con calma` | acción de retorno y sesión posterior | No usar ausencia, ánimo o energía para presionar |

## Reglas de descubrimiento

1. Sharing y referral aparecen sólo después de una revisión guardada, un hito o valor equivalente.
2. Premium aparece al intentar una capacidad limitada, no como banner genérico.
3. Una sugerencia se puede cerrar y respeta frecuencia; no reaparece en la misma sesión.
4. Ningún loop utiliza bienestar, finanzas, journal o texto personal como targeting.
5. Los enlaces internos llevan al siguiente paso concreto, no a una página promocional genérica.

## Diagnóstico de cortes

Si un loop no convierte, revisar en este orden: si el valor previo ocurrió realmente, si el CTA corresponde al contexto, si el evento está instrumentado, si existe fricción técnica y si la promesa coincide con el resultado. No aumentar presión o frecuencia para compensar un producto que aún no entrega valor.
