# ADR 0007: Sistema visual editorial sereno

**Estado:** reemplazada por [ADR 0008](./0008-current-typography-system.md) el 2026-09-09.

## Contexto histórico

Esta decisión propuso Cormorant Garamond para la voz editorial y DM Sans para controles. Esa combinación no llegó a consolidarse en la implementación y ya no representa la tipografía vigente.

La intención cromática continúa como antecedente histórico: el rosa se reserva para acción y progreso; crema, taupe, salvia y blush sostienen jerarquía y calma. Su vigencia ya no procede de este ADR, sino de los tokens implementados y de ADR 0008, que documenta la arquitectura actual de capas y la decisión tipográfica oficial.
